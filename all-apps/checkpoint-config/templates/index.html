How Pin Numbers Work

Enter the **channel number** (1, 2, 3...) not the register address.

Example: If you enter Pin "1" for a sensor with Input Start Address "8", it reads address 8 (8 + 0).

If you enter Pin "3", it reads address 10 (8 + 2).
