Register Mapping

Digital Inputs (Sensors)
DI1 = Start Address + 0, DI2 = Start Address + 1, etc.
Digital Outputs (Relays)
DO1 = Start Address + 0, DO2 = Start Address + 1, etc.
How Pin Numbers Work

Enter the channel number (0, 1, 2...) - these are 0-based offsets from the start address.

Example: If you enter Pin "0" for a sensor with Input Start Address "8", it reads address 8 (8 + 0).

If you enter Pin "2", it reads address 10 (8 + 2).
